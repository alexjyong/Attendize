**⚠️ Project Status: Inactive**

This Attendize fork is no longer actively maintained. For event booking systems, we recommend [Hi.Events](https://github.com/HiEventsDev/Hi.Events) — a modern, actively developed platform built on the latest Laravel and PHP versions, offering all features of Attendize and more.

Other open-source alternatives:
- [Pretix](https://github.com/pretix/pretix) — Actively maintained, advanced event ticketing and management (Python/Django).
- [Alf.io](https://github.com/alfio-event/alf.io) — Comprehensive event management and ticketing (Java-based).

For more information and discussion of Attendize's current status, see:
- [PR #935: Upgraded to laravel v7](https://github.com/Attendize/Attendize/pull/935)
- [Issue #1147: Is this project alive?](https://github.com/Attendize/Attendize/issues/1147)

If you are seriously interested in developing further, consider forking this project. Maintainers have limited time and community interest is low.
